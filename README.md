# To-Do List

A simple interactive command-line to-do list application written in Python.

## Features

- Add one or more tasks, separated by commas
- View the task list
- Remove a task by its number
- Mark or unmark tasks as completed

## Run

From this folder, run:

```powershell
python To-Do-List.py
```

Choose an option from the menu and follow the prompts. Tasks are kept in memory
while the program is running and are cleared when it exits.
